# Security policy

FRISQ is an early-stage starter engine (v0.3). It is not a certified or complete security product.

To report a vulnerability in FRISQ itself (for example a way to make `gate` approve without evidence, or the scanner leaking matched secrets), use private vulnerability reporting on this repository's **Security** tab. Please do not open a public issue for it, and never include real credentials or customer data in a report.
